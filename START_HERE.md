# Welcome to your Python workspace 👋

This Codespace goes with the **Python in 12 Weeks** course site. The site has the lessons, videos and quizzes; this is where you write and run your code.

## How each week works

1. Read the week's lesson on the course site.
2. Open the week's folder on the left, for example `weeks/week03_loops/`.
3. Open an exercise file like `ex1_add_them_up.py`, read the instructions at the top, and write your code.
4. Check it in the terminal (bottom of the screen; open it with **Ctrl + `** if you don't see it):

   ```
   python check.py 3 add_them_up
   ```

5. When it says **All passed**, tick the exercise off on the course site.
6. Build the week's `project.py` and run it with `python weeks/week03_loops/project.py`.

## Save your work to GitHub

Your files are saved inside the Codespace automatically, but to keep a copy on GitHub, commit them:
click the **Source Control** icon on the left (it looks like a branching line), type a message like `week 3 exercises`, press **Commit**, then **Sync Changes**.

## Tips

- The **Testing** panel (flask icon on the left) shows every test with a green tick or red cross. Click ▶ to run them.
- Codespaces stop after 30 minutes of inactivity. Your files are kept; reopen it from github.com/codespaces.
- Free GitHub accounts get a monthly allowance of free Codespace hours. Stop the Codespace when you finish a session to make it last.
