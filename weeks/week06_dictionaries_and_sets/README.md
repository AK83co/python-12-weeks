## Project: Gradebook

Keep track of students and their marks: add grades, see averages, and find the top student.

Run it with `python weeks/week06_dictionaries_and_sets/project.py`

- [ ] Store students in a dict: name → list of grades
- [ ] Add a command to add a student
- [ ] Add a command to add a grade for a student
- [ ] Show each student's average
- [ ] Find and print the top student
- [ ] Show a letter grade next to each average (reuse your week 2 grade function!)

**Stretch goal:** Track several subjects per student with a dictionary inside a dictionary.
