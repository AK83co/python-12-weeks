## Project: Hangman

The classic word-guessing game, built carefully with functions and good structure.

Run it with `python weeks/week11_algorithms_and_problem/project.py`

- [ ] Pick a random word from a list
- [ ] Show the word as underscores, revealing guessed letters
- [ ] Track guessed letters in a set and reject repeats
- [ ] Count wrong guesses and draw the hangman with text art
- [ ] Detect win and loss
- [ ] Split your code into small functions (display, check_guess, is_won)

**Stretch goal:** Add categories and difficulty, or let a second player type in the secret word.
