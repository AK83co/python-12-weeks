# Week 12: Real-world Python and your capstone

Set up Python on your own computer, meet the big libraries, and build something you're proud of.

**Goals:** Run Python locally · Read and write files · Install packages with pip · Ship a capstone project

## Exercises

Open each file, write your code, then check it in the terminal:

| File | Check it with |
|---|---|
| `ex1_two_sum.py` | `python check.py 12 two_sum` |
| `ex2_roman_numerals.py` | `python check.py 12 roman_numerals` |
| `ex3_group_by_length.py` | `python check.py 12 group_by_length` |
| `ex4_merge_sorted_lists.py` | `python check.py 12 merge_sorted_lists` |

Check the whole week at once: `python check.py 12`

## Project: Capstone: your own app

Build one bigger project on your own computer, using everything from the course. Pick an idea below or invent one: an expense tracker that saves to CSV, a quiz app that loads questions from JSON, a weather checker using requests, a Flask website, or a pygame game.

Run it with `python weeks/week12_real_world_python/project.py`

- [ ] Install Python and VS Code on your computer and run a hello-world file
- [ ] Choose your project and write a one-paragraph plan of what it does
- [ ] List the features: must-have first, nice-to-have later
- [ ] Build the smallest working version
- [ ] Save data to a file so it remembers between runs
- [ ] Use at least one class and handle errors with try / except
- [ ] Put it on GitHub with a README describing it
- [ ] Show it to someone and ask for feedback

**Stretch goal:** Add a menu, monthly summaries, and a chart with matplotlib (pip install matplotlib).
