# Week 1: Hello, Python

Run your first programs and learn to store text and numbers.

**Goals:** Use print() · Create variables · Do maths · Build text with f-strings

## Exercises

Open each file, write your code, then check it in the terminal:

| File | Check it with |
|---|---|
| `ex1_hello_world.py` | `python check.py 1 hello_world` |
| `ex2_about_me.py` | `python check.py 1 about_me` |
| `ex3_make_a_greeting.py` | `python check.py 1 make_a_greeting` |
| `ex4_seconds_in_some_days.py` | `python check.py 1 seconds_in_some_days` |
| `ex5_initials.py` | `python check.py 1 initials` |

Check the whole week at once: `python check.py 1`

## Project: Mad Libs story generator

Ask the player for some words, then print a silly story using them. Your first interactive program!

Run it with `python weeks/week01_hello_python/project.py`

- [ ] Ask for at least 4 words with input() (an adjective, an animal, a place, a food…)
- [ ] Store each answer in a well-named variable
- [ ] Print a 3–4 sentence story using f-strings
- [ ] Add a title line and make the output look tidy
- [ ] Show it to someone and let them play

**Stretch goal:** Make the story longer, ask for a number and do maths with it (“the 7 cats ate 14 pizzas”), or write two different stories.
